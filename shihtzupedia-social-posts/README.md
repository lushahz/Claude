# Shih Tzu Pedia social media posts

One folder per blog post or site page, grouped by site category. Each folder holds:

| File | Platform | Size |
|---|---|---|
| `<slug>-facebook.jpg` | Facebook feed | 1080x1350 (4:5) |
| `<slug>-instagram.jpg` | Instagram feed | 1080x1440 (3:4) |
| `<slug>-pinterest.jpg` | Pinterest pin | 1000x1500 (2:3) |
| `<slug>-twitter.jpg` | X / Twitter | 1280x720 (16:9) |
| `captions.md` | All four captions, plus Pinterest title, board, topics, and alt text | |

`all-captions.csv` has every caption in one sheet.

Photos come from each article's own featured image on shihtzupedia.com. Only the brand overlay was added.
Keywords come from each article's SEO title and description, cross-checked against Google autocomplete.
